## Findings

**F1. Full frames were not saved (critical).** `board.py` geometry, the
thresholds and the pip fixes were all fitted to frames that were pasted
into a chat session and then discarded. The only large image on disk is a
debug crop (`data/_stats2.png`). Without the frames, nobody can reproduce,
regress or measure the board work.
→ Store every full frame under `tests/frames/full/` with a sidecar before
the next CV change.

**F2. Pixel constants are tied to downscaled screenshots.** The reference
geometry is 1024×575, which looks like a chat-downscaled image, not a
native capture. Regions are stored as fractions, which is good. Several
gates are still absolute pixels: `_BAR_MAX_H=4`, portrait side 14–40 px,
pip runs of 2–8 px, ±3 px merge slack. A native 1080p/1440p capture in S2
will break them silently.
→ Pick one canonical working resolution, resize every frame to it before
extraction, and collect native-resolution frames now. This moves from S2
to S1.

**F3. S1 has not started and gates everything after it.** The live loop
(S2) needs gold, level, XP, stage and HP. Board work cannot reach the
engine without them.

**F4. The 3D template library is sunk cost.** Freeze it. It stays
available as a fallback or tie-breaker, but nothing more goes into it
until the stats-panel path is measured. The KR trait→variant map in its
manifest is still useful for the trait-panel reader.

**F5. Two board identifications need confirmation.**
(a) `bench_portraits` reads a 9-slot portrait column on the far-left edge.
TFT's bench normally shows 3D units in a row under the board, so check on
more frames that this column really is the bench. (b) The trait-row
`active` flag uses icon saturation, which the log itself calls unreliable
for blue-tinted icons.

**F6. Knowledge is going stale with no automation.** The 3-day threshold
is reached today. There is still no augment data, so CHOOSE_AUGMENT runs on
need-based heuristics only.

**F7. Doc drift has returned.** The README still says "14/65 3D model
crops; matcher not built yet". The ROADMAP revision log has grown into a
per-commit diary: 10 rows on template collection, 6 of them about Lux
variants. That makes the plan hard to read.

**F8. No perception benchmark command.** `evaluation/runner.py` measures
decisions only. The S1 exit criterion (≥98% HUD exact-match) has no tool
to measure it.
